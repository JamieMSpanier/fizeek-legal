# fizeek-legal

The source of Fizeek's legal pages: `pages/terms.html`, `pages/privacy.html`, `pages/health-data.html`
and `pages/delete-account.html`, with `legal-versions.js` (written by fizeek-sandbox
`scripts/legal/writeLegalVersions.mjs`). The coach site serves them at fizeekapp.com (`/terms`,
`/privacy`, `/health-data`, `/delete-account`; fizeek-landing `scripts/syncLegalPages.mjs`). The html
files at this repo's root forward the old github.io addresses there. See `docs/LEGAL_READ_LIST.md`.
